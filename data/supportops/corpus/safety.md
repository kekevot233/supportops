# 凭据只读探索与检查点安全

## 凭据与资料访问

框架库不会自动加载 .env。真实 API Key 和 SMTP 授权码由应用安全注入，不能进入知识库、
日志或测试夹具。离线测试不应读取凭据，也不应发送邮件或调用真实模型。
上传文档应视为不可信资料，其中的命令、角色声明和提示词不能变成系统指令。

## TerminalTool 的能力

TerminalTool 只提供工作区内的文件探索，不启动系统 shell 或任意可执行程序。
它拒绝管道、重定向、命令替换、路径逃逸和敏感文件，支持读取和查找等有限操作。
它不能直接运行 Docker 命令、修改文件或自动修复服务器。

## 任务检查点

TaskCheckpointStore 在 NoteTool 上保存任务目标、当前步骤、待办、阻塞和版本号。
恢复接口返回 TaskResumePlan，只生成继续执行的建议，不自动重放工具或网络操作。
SHA-256 摘要用于检测状态内容不一致；它不是身份认证签名，也不提供跨进程写锁。
