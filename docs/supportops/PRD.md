# SupportOps 第一阶段产品需求

版本：0.9；日期：2026-10-17；状态：P0～P4、P5a/P5b、P5c-1 离线预检及 P5c-2 三题真实试跑已实现；完整题集、广泛语义质量与生产认证待验证。

## 产品定位

SupportOps 是面向研发人员的知识与技术支持助手，使用 HelloAgent 作为底层框架。
首个演示领域是 HelloAgent 的安装、文档知识库、记忆、工具调用和故障排查。
用户通过工作台查资料、核对引用、反馈问题；后续P6a已接入本人私有工单、引用建议与人工
处理记录，见 [工单说明](P6_TICKETS.md)。受控诊断和团队派单仍待实现，本文首版验收不据此自动改为通过。

目标用户：刚接手项目的研发人员、维护项目知识库的技术负责人、处理重复问题的支持人员。
首批资料由项目文档和代码整理而成，明确标注为项目说明，不声称来自真实企业客户。

## 用户旅程

1. 管理员创建项目空间，上传经过授权的文档，查看解析、切块、索引状态。
2. 研发人员选择空间并提问，例如“扫描版 PDF 为什么无法检索？”
3. 助手检索可访问的当前版本资料，回答并引用具体章节和原文片段。
4. 资料不足时明确说明缺少什么，避免用相关但不支持结论的资料作答。
5. 用户点击引用核对原文，提交有用/无用反馈及原因。
6. 管理员查看失败问题、索引任务、错误码和耗时，修正文档后重新验证。

## 第一版范围与验收

| 编号 | 功能 | 验收要求 |
| --- | --- | --- |
| M01 | 空间与身份 | 服务端从已验证身份获取成员关系；无权限访问返回 403 或不泄漏资源存在性的 404 |
| M02 | 文档管理 | 支持 Markdown/TXT；PDF/DOCX 随可选依赖启用；显示处理状态和稳定文档标识 |
| M03 | 异步索引 | 上传返回任务 ID；重启后能发现未完成任务；失败任务可显式重试 |
| M04 | 更新和删除 | 更新成功后才切换当前版本；删除后查询不能继续使用旧块；同请求重复提交不重复创建版本 |
| M05 | 问答与引用 | 正常答案有可核对证据；引用定位到原文和版本；过期引用显示失效状态 |
| M06 | 会话 | 按空间隔离，临时检索资料不写入长期消息；失败不提交半轮消息 |
| M07 | 反馈与追踪 | 反馈关联真实存在的回答；同一用户可更新反馈；运行记录包含耗时、Token 来源和错误码 |
| M08 | 部署 | 本地可启动、可检查健康状态、能重启恢复；默认不执行诊断命令或发送邮件 |

首版演示可以只有一个空间和两个预置角色，但“演示身份”必须可见；对外提供多用户服务前
必须完成真实认证和成员权限，不能信任请求正文传入的 user_id。

## 不在第一版内

- 自动修复服务器、任意 shell 执行、退款等外部写操作。
- 全量复制 Onyx、企业 SSO、数十种第三方连接器。
- 扫描件 OCR、完整复杂 PDF 版面还原、音频视频问答。
- 在线自动学习所有回答；知识发布需要审核，错误回答不能自动成为权威知识。
- 将全部 Agent 范式、Neo4j 或多 Agent 强行放入每个问答流程。

## 资料与测量

`data/supportops/corpus/` 为独立知识目录；`data/supportops/evaluation/` 为验收数据，
后者不进入摄取清单。首批 10 份项目知识、25 个检索用例和 5 个应用验收场景。
这些数据是公开的开发 smoke 集，不是盲测集；可以检查数据链路，但不能据此宣称生产准确率。

检索度量：gold 文档 Recall@5、支持片段命中率、MRR@5、引用字符区间一致性。
P0 检索评测仍独立运行；P1/P2 另行验证空间、成员、文档任务、更新隔离与版本引用，demo search
已接空间权限；P3 已增加私有会话、严格抽取式引用回答与 WSGI JSON 路由，但仅以 Fake 验证，
P4 已补充仅限 127.0.0.1 的随机会话工作台与真实浏览器验收。语义拒答、真实模型抗注入及
生产认证仍未完成，不能把工程验收当作真实模型准确率；具体见 [P4 说明](P4_WORKBENCH.md)。
首版检索建议门槛：Recall@5 >= 0.90，引用区间正确率 1.0；实际结果必须原样记录。

应用上线门槛另行测量：答案事实正确性、引用支持性、无资料时拒答、跨空间泄漏为零、
失败任务恢复、P50/P95 延迟与每次已解决问题的成本。LLM 自述置信度不作为正确性证明。
Token 区分 tokenizer 估算和服务实际 usage，缺失 usage 时不能填入虚构精确值。

## 差异化与演示方式

面试重点是可追溯知识、历史隔离、可恢复任务、受控工具和可测量效果。
演示依次比较：直接模型回答、文档 RAG、加入历史案例和只读诊断后的结果。
本阶段只有检索基线，后两种实验需在能力实现并完成真实评测后再报告。
