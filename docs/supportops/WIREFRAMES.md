# SupportOps 工作台页面草图

本文件保留 P0 低保真设计；P4 已实现对应本机工作台，实际范围见 [P4 说明](P4_WORKBENCH.md)。
草图中的数量和答案仍是示意，不是实测模型输出。

## 共同布局

```text
┌─────────────────────────────────────────────────────────────┐
│ SupportOps     项目空间：[HelloAgent ▾]       当前身份/角色   │
├────────────┬────────────────────────────────────────────────┤
│ 知识问答   │ 页面标题                                       │
│ 文档管理   │ 索引模式 / 模型模式 / 当前知识版本               │
│ 运行记录   │                                                │
│ 项目设置   │ 当前页面内容                                   │
└────────────┴────────────────────────────────────────────────┘
```

演示模式显示固定横幅：“本地演示身份，非企业认证”。离线检索模式始终显示“仅返回原文证据，
未调用 LLM”，不能让用户把检索片段当作模型已经验证的诊断。

## 页面一：文档管理

```text
文档管理                                  [上传文档]
搜索标题 [________________]     状态 [全部 ▾]

标题             当前版本  状态       操作
文档加载说明     v1        已就绪     原文 / 更新 / 删除
部署手册         v2        处理中     查看任务
扫描件           v1        处理失败   查看原因 / 重试

任务详情：解析 → 切块 → 向量化 → 提交当前版本
错误：NO_TEXT_LAYER；提示需要 OCR；旧版本继续可查
```

上传前展示类型和大小限制；失败保留可理解的错误码。删除弹出确认并说明影响。
界面隐藏不具备权限的管理操作，但实际权限仍由服务端检查。

## 页面二：知识问答与引用

```text
会话列表        当前会话                     原文证据面板
─────────       ──────────────────────       ──────────────
+ 新会话        我：扫描版 PDF 能检索吗？    [D1] 文档加载说明
环境部署        助手：当前需要文字层；        版本 v1 / 章节
知识库使用      无文字层时需先完成 OCR。[D1]  原文片段（高亮）
                [有用] [无用]                来源与版本状态

                输入问题 [_______________] [发送]
```

点击引用先检查权限；原件已删除显示“来源已失效”，不打开其他版本替代。
证据不足单独显示“需要补充：版本、错误信息、部署方式”，不显示虚构引用。
服务故障显示“请求失败，可以重试”；与证据不足使用不同状态。

## 页面三：运行详情与反馈

```text
运行记录：request_id          状态 answered / failed
检索：资料版本、候选数量、入选来源、引用
模型：模式、模型名、输入/输出 Token、估算或服务实际 usage
耗时：检索 / 生成 / 总耗时
预算：历史裁剪轮次、临时资料移除数量
反馈：有用 / 无用 → 引用不相关 / 结论错误 / 资料过时 / 其他
```

只显示有权查看的运行。默认不展示密钥、系统环境、本机绝对路径和完整提示词。
没有实际模型调用时，显示“未调用”，不填充模拟 usage 或成本。

## 演示顺序

1. 查看已就绪文档，核对来源和版本。
2. 提问并点击原文引用。
3. 提交无用反馈，进入运行记录查看检索证据。
4. 更新资料，等待任务成功后再次提问。
5. 切换无权限空间，确认服务端拒绝访问。

P4 已通过浏览器执行对应工程流程，仍用 Fake 原文选择器，不代表真实模型语义质量。
